> Бывало, что тебя ганкал другой агент, пока ты печатал в мультиагентном воркфлоу Herdr?

Ты запускаешь в Herdr агента-PM и несколько воркеров. Ты на полпути к промпту для PM, и тут воркер отчитывается — прямо в то же поле ввода. Один Enter — и оба текста уходят как один исковерканный запрос.

**До**

![Без Holdback: сообщение воркера вставляется в промпт PM, который ты как раз писал, и оба текста отправляются как один исковерканный запрос](./media/demo-before.gif)

Holdback заставляет их ждать своей очереди. Сообщения для pane, на который ты смотришь, выстраиваются в панели над ним и приходят, когда ты закончишь.

**После**

![С Holdback: сообщение воркера ждёт в панели над pane PM, пока ты дописываешь и отправляешь свой промпт; затем клик по панели доставляет его отдельным сообщением](./media/demo.gif)

- **Поле ввода остаётся твоим** — пока ты печатаешь, ничего не вставляется; доставка ждёт, пока поле опустеет.
- **Видно, кто ждёт** — панель показывает, сколько сообщений в очереди, от кого они и их первые слова.
- **Забирай, когда удобно** — кликни по панели или нажми клавишу, чтобы увидеть список; сообщения поступают в порядке прихода.
- **Подписанные сообщения** — начни сообщение с `имя 💬 `, и панель покажет, от какого агента оно.
- **Или просто иди дальше** — переключись на другой pane, и очередь будет доставлена по порядку.
- **Остальные pane не затронуты** — сообщение для pane, на который ты не смотришь, доставляется сразу.

## Установка

Нужны Herdr 0.9.3 или новее и Node 18 или новее.

```sh
herdr plugin install navishachiku/herdr-holdback
```

Назначь клавишу в `~/.config/herdr/config.toml` и перезагрузи конфигурацию через `prefix+shift+r`:

```toml
[[keys.command]]
key = "alt+i"
type = "plugin_action"
command = "herdr-holdback.open"
description = "open the holdback list"

# Notifications are off by default; the queue notice needs this.
[ui.toast]
delivery = "herdr"
```

## Ограничения

- Если доставка не удалась, отправка очереди прекращается, а остальное остаётся в очереди; ничего не теряется.
- Если фокус полностью уходит из Herdr (ты переключился на другое приложение), ничего не доставляется, пока фокус не перейдёт на другой pane.

### Отправка сообщения

Всё, что хочет поставить своё сообщение в очередь, пока ты смотришь, идёт через `src/send.mjs`:

```sh
node ~/Project/herdr-holdback/src/send.mjs --to w1:p2 "Task-58/TL 💬 gate 1 reached"
```

Текст перед ` 💬 ` берётся как отправитель в уведомлении; чтобы указать его явно, передай `--from`. Вывод — одна строка JSON: `{"ok":true,"queued":true,"count":2}`, если сообщение придержано, и `"queued":false`, если доставлено сразу. Сообщения в pane с агентом идут через `herdr agent prompt`, в обычный терминал — через `herdr pane run`.

Этот репозиторий даёт только очередь и точку входа. Сделать так, чтобы твои агенты вызывали её вместо `herdr agent prompt`, — задача твоего собственного защитного слоя отправки.

### Как это работает

| Часть | Роль |
| --- | --- |
| `src/daemon.mjs` | Постоянно работающая очередь. Решает, ставить в очередь или доставлять, опустошает очередь при уходе фокуса, держит панель над pane. По одному запросу за раз. |
| `src/on-focus.mjs` | Хук `pane.focused`. Событие Herdr не сообщает, какой pane покинут, поэтому демон сам запоминает прежний фокус и при запуске заполняет его из `herdr pane list`. |
| `src/open.mjs`, `src/list.mjs` | Действие клавиши и всплывающий список. |
| `src/send.mjs` | Точка входа для отправителей. |

Когда самое старое сообщение ждёт 5 минут, а поле ввода пусто, вся очередь доставляется по порядку; демон проверяет это каждые `check_interval_seconds` (см. «Настройка»).

Очередь хранится в файле, поэтому перезапущенный демон продолжает с того места, где остановился. Состояние лежит в `~/.local/state/herdr/plugins/herdr-holdback/` (`queue.json`).

### Настройка

При первом запуске `config.toml` записывается в каталог конфигурации плагина (`herdr plugin config-dir herdr-holdback`):

```toml
check_interval_seconds = 30
```

Как часто демон проверяет, нет ли в pane, на который ты смотришь, сообщений, ждущих 5 минут. По умолчанию 30 секунд; чтобы изменение вступило в силу, перезапусти демон. Сами 5 минут ожидания не настраиваются.

### Тесты

```sh
npm test
```

Запускает настоящий демон и настоящие точки входа против поддельного бинарника `herdr`. Тестам всплывающего списка нужен `python3` для псевдотерминала.
